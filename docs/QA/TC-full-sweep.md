- **검증**: 리빌드 후 재캡처 — 헤딩 중복 해소.

### ISSUE-2 · 스탬프(도장책) 인증 pending 시 에러 오표시 · 🟠 Medium · ✅ **수정 완료**

- **TC**: H-02 · **플랫폼**: 공통
- **증상**: `/mypage/stamps` 진입 시 "도장 정보를 불러오지 못했어요 / 다시 시도" 에러 상태 표시.
- **근본 원인**: `useStamps` 는 `enabled: isAuthenticated`. React Query v5 에서 쿼리 disabled(인증 하이드레이션 전) 상태면 `status='pending'` + `fetchStatus='idle'` → **`isLoading`=false** 인데 `data`=undefined. `StampsClient` 의 분기 `if (isError || !data)` 가 이 "아직 로드 전" 상태를 **"로드 실패" 에러로 오표시**. (세션쿠키 유효하나 zustand persist 미하이드레이션 시 실제 발생 가능)
- **수정**: `StampsClient.tsx` 분기를 `isError`(진짜 실패)일 때만 에러, `isLoading || !data`는 skeleton 으로 graceful 처리 (ProfileCard 등 형제 컴포넌트 패턴과 일치).
- **검증**: 리빌드 후 재캡처 — 에러 상태 미노출(로딩 skeleton 으로 전환), 단위 테스트 250 통과.

### ISSUE-3 · 홈 카드 좌상단 검은 사각형 · 🟡 Low · ✅ **규명 완료 (앱 결함 아님 — 수정 불필요)**

- **TC**: B-04 · **플랫폼**: mobile-safari-ios(**headless WebKit**) 에서만 관찰
- **증상**: 홈 캐러셀 슬라이드 좌상단에 검은 사각형이 스크린샷에 캡처됨.
- **규명(진단 스펙으로 확정)**: 해당 좌표를 `elementsFromPoint` + 전체 요소 rect 스캔(pointer-events·pseudo 포함) 해도 **검은 DOM 요소가 존재하지 않음** — 최상위는 슬라이드 gradient / 흰색 뷰포트뿐. Chromium(desktop-mac) 에선 전혀 미관찰. 즉 `Carousel .viewport` 의 GPU 레이어 승격(`transform: translateZ(0)` + `backface-visibility`) backing store 를 headless WebKit 래스터가 검게 그리는 **테스트 환경 컴포지팅 아티팩트**. 실기기 iOS Safari/Chromium 에는 재현되지 않음.
- **조치**: CSS 배경 초기화 시도했으나 backing-store 래스터 이슈라 무효 → 되돌림. **코드 변경 없음.** (실기기 회귀 검증은 운영 QA 로 이관)

### ENV-1 · 프로덕션 빌드 blocker: `recharts` 미설치 · ⚙️ 환경 (해소됨, 재발주의)

- **증상**: 최초 `next build` 시 `Cannot find module 'recharts'` 로 컴파일 실패.
- **원인**: `recharts@^2.13.0` 이 package.json·package-lock 엔 존재하나 로컬 `node_modules` 에 미설치(설치 drift). 홈 디렉토리 stray lockfile(`/Users/jeonwoonggu/package-lock.json`) 로 Next 가 워크스페이스 루트 오추론 경고도 동반.
- **조치**: `npm install` 로 로컬 해소(recharts@2.15.4 설치). 코드 결함 아님.
- **재발 방지 제안**: CI/신규 clone 시 `npm ci` 강제, 홈 stray lockfile 정리, `outputFileTracingRoot` 설정으로 워크스페이스 루트 경고 제거.
